Симулятор смотрителя отеля
Репозиторий: https://github.com/ArtemyAlert/Hotel-Caretaker

Актуальность
Удаленно обучить нового смотрителя отеля сложно. Обычные текстовые инструкции не дают практики, а человеку нужно заранее понять, как следить за оборудованием и помещениями, чтобы ничего не сломать на реальной смене.

Цель
Сделать простой 3D-тренажер для отработки базовых действий смотрителя по контролю и управлению объектом.

Задачи
- Собрать 3D-локации отеля (подвал с печью, комнаты, коридоры).
- Добавить взаимодействие с приборами, окнами и кнопками.
- Разместить на старте понятную инструкцию по шагам.

Функционал
- Инструкция прямо на стене в точке старта, чтобы не запутаться.
- Проверка давления на отопительной печи и сброс давления вентилем.
- Закрытие открытых окон в комнатах.
- Включение охранной сигнализации по кнопке.
- Выход из симулятора через дверь с табличкой EXIT.

Аудитория
Новые смотрители отелей и баз отдыха, а также управляющие, которым нужно быстро и удаленно ввести сотрудника в курс дела.

Технологии
Unity, C#, Blender, Visual Studio.

Управление
WASD - ходить, мышь - смотреть, пробел - прыжок, клик мышью - взаимодействие с предметами.
